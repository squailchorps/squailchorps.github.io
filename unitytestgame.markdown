## Overview

In order to get an understanding of the Unity game engine, I decide to forgo doing some of the usual tutorials for a more hands on approach.
I followed a guide by Gamemaker's Tool Kit to make "Flappy Bird". I followed it, and then added a few things, like the out of bounds game over, 
and a main menu. While crude, I believe that it is a great start in understanding Unity and trying my hand at something new! 

[Here is a link to the game to try out on itch.io](https://squirrelchips.itch.io/a-bird-that-flaps)
